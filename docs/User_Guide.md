# WHEELTEC C50X 调试监视器使用手册

本文对应本仓库当前上位机界面。软件由顶部的 **汇总、编码器、IMU、ROS、ROS IMU、ROSBag、定位精度** 七个模块组成。使用前先确认机器人、串口设备和 ROS 主机处于预期状态；涉及运动的按钮会向机器人发送真实控制命令。

## 1. 安装与启动

### 1.1 电脑和依赖

推荐在 Windows 上使用 Python 3.11 或更新版本，并安装 `uv`。在仓库根目录执行：

```powershell
uv venv .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.venv\Scripts\python.exe src\main.py
```

后续启动只需运行最后一行。若已有符合要求的虚拟环境，可用该环境的 Python 启动。依赖定义见 [`requirements.txt`](../requirements.txt)。

### 1.2 连接前检查

| 功能 | 需要的设备或服务 |
| --- | --- |
| 编码器、PID、USART1 目标控制 | 机器人调试 UART1、USB 转 TTL 串口、对应固件 |
| IMU | 一台或两台支持本项目协议的串口 IMU |
| ROS、ROS IMU、ROSBag、定位精度 | 可访问的 ROSbridge WebSocket；相关操作还需要对应 ROS topic、`rosapi` 或 `launch_manager` |
| 汇总中的谐波雷达 | 雷达连接及雷达软件生成的 `.bin`；具体取决于所选雷达来源 |

调试 UART 默认 **115200 bps，8N1**。USB 转 TTL 接线为机器人 TX（PA9）接转换器 RX、机器人 RX（PA10）接转换器 TX，GND 对 GND。不要把 TTL 串口直接接到不匹配的电平接口。协议字段见 [调试串口协议](Debug_UART_Protocol.md)。

ROSbridge 端口默认为 `9090`。主机地址应按电脑当前连接的网络填写，见第 5.1 节；界面当前预填的 `192.168.0.14` 不一定适用于当前网络。连接前确保电脑能访问该主机，ROS 主机已启动 `rosbridge_server`；需要时间探测、建图控制或节点管理时，还需 `rosapi`、相应参数和 `launch_manager`。

## 2. 第一次使用的推荐顺序

1. 启动程序，在顶部选择要用的模块。编码器模块是默认页面。
2. 仅使用串口时，在 **编码器** 或 **IMU** 页面选端口和波特率，点击 **连接**，确认帧数持续增加。
3. 使用 ROS 功能时，先在 **ROS** 页面填写主机、端口并点击 **连接**；其余 ROS 页面共享这条连接。
4. 在 ROS 页面选择需要的数据 topic，点击 **应用订阅**。定位数据还要勾选 **FAST-LIO 里程计** 并应用。
5. 先观察实时数值、状态和曲线，再按需要发送控制命令或开始记录。
6. 结束时先发送停止运动命令，停止记录并确认保存提示，再断开连接。

窗口底部状态栏显示总体状态、串口帧数和错误数。**连接成功**只表示通信通道已建立；数据是否到达还要看帧数、topic 状态和实时值。

## 3. 编码器：实时监视、参数和回放

### 3.1 连接与观察

在 **编码器** 页点击 **刷新**，选择调试串口端口，保持波特率 `115200`，点击 **连接**。左侧显示速度、PWM/AFC 等曲线；右侧可切换 **固件参数、当前数据、统计分析**。曲线支持缩放，**暂停绘图**只暂停画面刷新。无数据时先检查端口、接线、波特率和固件是否发送调试帧。

### 3.2 发送参数和目标值

右侧 **PID 设置** 可分别填写电机 A、B 的 `Kp/Ki/Kd`，用 **同步设置 A/B** 或 **设置 A/B** 下发。**载入设备 A/B** 将已查询到的对应设备参数填入控件，便于修改。**速度参数**可分别设置遥控速度限制、最大速度和平滑步进。**USART1 目标控制**可发送两轮目标速度或 PWM。点击 **查询参数**，收到参数帧后在 **固件参数** 页核对返回值。

参数和目标命令会立即影响固件行为。调参时保持机器人处于可控状态，先用小的目标值确认方向与响应；最终以固件返回的参数和实际数据为准。

### 3.3 单独记录与 CSV 回放

- 点击 **开始记录** 开始流式记录；再次点击 **停止记录** 后，在弹出的保存对话框选择 CSV 路径。取消保存会丢弃本次临时记录。
- **清空数据** 清除当前绘图/统计缓存，不等于删除已保存文件。
- 选择 **回放** 并点击 **加载 CSV**，可用 **播放/暂停**、进度条及 `0.5x / 1x / 2x` 查看记录。完成后切回 **实时**。

回放用于查看已保存数据；发送参数前仍需确认真实串口连接和机器人状态。

## 4. IMU：双串口采集

**IMU** 页面为 A、B 两台设备分别提供端口、波特率、连接和断开按钮。两台设备可独立连接。连接后可查看加速度、角速度、欧拉角曲线及当前值；**暂停绘图**和 **清空数据**只影响当前显示。

点击 **开始记录** 可记录已连接设备的数据，按钮会显示 A/B 写入行数。再次点击停止后，独立 IMU 会话保存在启动程序时工作目录下的 `recordings/` 子目录；页面会显示实际路径。记录目录中包含每台设备的 CSV、合并对齐 CSV 和会话元数据。若要与编码器、ROS 数据放在同一个实验目录，使用第 8 节的 **汇总** 页面。

## 5. ROS：连接、订阅、控制与 CSV

### 5.1 连接和 topic

先确认电脑连接的是哪一个网络，再在 **ROS** 页填写对应的主机地址；端口保持 `9090`，点击 **连接**：

| 电脑连接的网络 | ROS 主机 IP |
| --- | --- |
| 小车的 Wi-Fi | `192.168.1.100` |
| `RDRC_A10` | `192.168.1.14` |

ROS 页面、ROS IMU 页面、ROSBag 页面和定位精度页面共享同一个 ROSbridge worker；在任一相关页面断开会影响其他页面。连接成功后可在 ROS 页面选择小车话题；勾选并点击 **应用订阅** 后，若小车正在发布对应消息，就能看到部分话题的实时数值以及速度等相关曲线。ROS 连接状态和健康状态分别显示 WebSocket 与探测结果；`数据静默`表示连接可能仍在，但已订阅数据暂时没有消息。

在 **ROS 数据 topic 订阅** 中选择 `/odom`、`/imu`、`/active_imu`、电压或底盘诊断等 topic；可用 **基础低带宽、定位、诊断、全选、全不选** 快速勾选。勾选完成后必须点击 **应用订阅**，才会改变实际订阅。FAST-LIO 里程计 topic 可在 ROS 页或定位精度页编辑，两页共用设置；两页的勾选状态会同步，但实际启停也需点击 **应用订阅**。

### 5.2 观察和发送命令

**ROS 数据**区显示收到的速度、位姿、IMU 和电压等值；**速度监视**显示左右轮实际和目标速度。`/cmd_vel` 区可输入 `linear.x`、`angular.z` 并点 **发送**，**停止**发送零速。**PID 直行控制**提供前进、后退、停止，以及 PID 节点和雷达直线校准节点的启动、停止按钮。节点状态依赖 `/launch_manager/status` 返回，按状态标签确认节点已经运行后再发运动命令。

**重启 ROSbridge** 通过 SSH 在当前 ROS 主机重启 WebSocket 节点，完成后尝试重连和恢复订阅。此功能要求从电脑到 `wheeltec@<ROS 主机>` 的免密 SSH 可用，且远端满足项目配置的启动命令；它不是普通的“重新连接”按钮。

### 5.3 单独保存 ROS CSV

点击 **ROS CSV 记录 → 开始记录**；停止时在文件对话框选择 CSV 位置。取消对话框会丢弃这次记录。需要同时保存多类数据及统一时间信息时，使用 **汇总** 页面。

## 6. ROS IMU：比较两个 ROS 话题

**ROS IMU** 页面显示 `/imu` 和 `/active_imu` 的加速度、角速度及姿态曲线和当前值。可在此页填写主机、端口并连接，也可使用 ROS 页已建立的共享连接。**平滑**下拉框控制显示曲线的时间窗口，**显示原始数据**用于对照未经平滑的曲线；**暂停绘图**和 **清空数据**只影响此页显示。若两个话题的帧数均不增长，检查 ROSbridge 连接及消息发布情况。

## 7. ROSBag：车端录制与管理

### 7.1 开始和停止车端 rosbag

先连接 ROSbridge，再进入 **ROSBag**。在 **录制配置** 选择模式：`control`、`fastlio`、`trajectory_environment`、`fallback_no_fastlio`、`full` 或 `custom`。模式会勾选相应 topic，并更新文件前缀；可继续增减勾选，或在 **自定义 topic** 中输入以逗号或空格分隔的 topic。检查 **车端目录**（默认 `/home/wheeltec/bags`）、分片大小（默认 2048 MB）及压缩方式（默认 `lz4`），然后点击 **开始车端 rosbag**。

在 **当前车端 rosbag** 区确认状态、`session_id`、文件大小、topic 数和错误。结束时点击 **停止车端 rosbag**，随后点击 **查询状态** 与 **刷新列表**，确认车端已停止并列出文件。按钮发出请求后，应以车端返回状态为准。

### 7.2 查看、同步和清理

在 **车端 rosbag 列表** 选中一个 session，可 **查看详情**、**同步到 Windows**、**移到车端回收站** 或 **永久删除**。同步会将车端文件复制到本地；独立同步默认使用 `D:\debug_monitor\recordings\rosbags\<session_id>`，汇总会话关联的同步则使用该会话的 `raw/rosbag/`。同步完成后查看列表中的“已同步”状态和本地文件。

**移到车端回收站**和**永久删除**都有确认弹窗。永久删除弹窗显示 session、状态、大小、远程目录及不可恢复提示；正在录制的 session 会被拒绝删除。执行清理前核对所选行及本地同步结果。

## 8. 定位精度：轨迹、地图和雷达直线校准

先在 **ROS** 页连接 ROSbridge。在 **定位精度** 页确认 FAST-LIO 里程计 topic，勾选 **FAST-LIO 里程计** 并点击 **应用订阅**。页面使用共享连接，顶部的连接按钮会提示“请在 ROS 页连接”。收到里程计后，左侧绘制轨迹，右侧显示实时位姿和误差统计。

- **设置当前为起点**：将当前位姿作为直线测试基准；**清空轨迹**重置当前显示数据。
- **开始定位记录**：记录定位样本；停止时选择 CSV 文件。**生成测试摘要**保存 Markdown 报告。
- **启动/停止 FAST-LIO** 和 **启动/停止雷达节点**：通过车端 launch manager 控制节点，观察页面返回的节点状态。
- **冻结建图**：通过 ROS 参数暂停地图更新并获取冻结地图；**保存地图与轨迹数据**导出 ZIP，要求已获取冻结地图且有轨迹样本。恢复建图后冻结地图覆盖层会清除。
- **雷达直线校准**：启动校准节点，待状态确认运行后设置目标速度，使用 **前进、后退、停止** 控制。结束时先点 **停止**，再停校准节点。普通 PID 节点与校准节点共用控制节点标识，不应同时启动。

定位误差是相对于设置的测试起点及参考直线计算的指标；报告适合保存测试结果，不能替代外部真值测量。

## 9. 汇总：一次实验同步记录多种数据

**汇总**页用于在一个会话中记录多种来源。按以下顺序操作：

1. 在 **保存目录** 选择根目录；默认是 `D:\debug_monitor\recordings`。`Session` 留空时，开始记录会生成 `session_YYYYMMDD_HHMMSS`。
2. 在 **轨迹主话题** 选择 FAST-LIO `/Odometry`、`/odom` 或自定义 `nav_msgs/Odometry` 话题。
3. 在 **可记录数据源** 勾选本次真正需要的来源。当前界面初始化时均为未勾选；可选 ROS 话题、编码器、IMU A/B、谐波雷达 `.bin` 和 HR2.3。
4. 对勾选的串口来源，在下方分别选端口、波特率并连接；ROS 来源先在 ROS 页连接。雷达来源按页面提示填写目录、XML 或 HR2.3 主机端口，并使用相应的 **测试** 按钮。
5. 填写备注。需要联动车端 rosbag 时勾选 **同步车端 rosbag 录制**，并先确认 ROSbridge 和车端 rosbag 服务可用。
6. 点击 **检查可记录数据源**。检查期间等待结果；若已勾选来源显示离线或错误，修复连接或取消勾选后再开始。
7. 点击 **全部开始记录**；状态显示写入行数和当前进度。完成实验后点击 **全部停止记录**，等待 CSV 收尾、对齐和打包完成，再用 **打开目录** 检查文件。

**取消本次记录**会停止并丢弃这次汇总会话，适用于误启动。不要把它当作保存按钮。某些车端或雷达操作是异步的，看到“请求已发送”后继续检查最终状态。

### 9.1 汇总输出

每次会话生成独立目录，常见文件如下。实际文件取决于勾选的数据源和是否收到数据：

| 路径 | 内容 |
| --- | --- |
| `session.json` | 本次配置、时间、检查结果、错误和输出路径 |
| `encoder.csv`、`imu_A.csv`、`imu_B.csv` | 对应串口来源记录 |
| `trajectory_odometry.csv` | 选定轨迹主话题的数据；默认 `/Odometry` 时还会生成兼容用的 `fastlio_odometry.csv` |
| `ros_*.csv`、`akm_state.csv` 等 | 已启用的 ROS 数据来源 |
| `raw/` | 原始数据副本及雷达解析结果；车端 rosbag 同步文件可能位于 `raw/rosbag/` |
| `aligned/` | `trajectory_aligned.csv`、`chassis_100hz_aligned.csv` 等时间对齐结果 |
| `manifest.json`、`<session_id>.zip` | 文件清单及汇总包；大型 `.bag` 文件不自动装入 ZIP |

ROS 数据尽量保留消息头的 ROS 时间 `ros_time` 和本机接收时间。跨设备对齐仍受时钟、网络延迟和实际消息频率影响；分析前先核对 `session.json` 中的数据源检查结果及各 CSV 行数。

## 10. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 串口列表为空或无法连接 | 插拔设备后点 **刷新**；在设备管理器确认 COM 口；检查是否被其他软件占用。 |
| 串口已连接但帧数不增长 | 检查 TX/RX 交叉、GND、波特率、固件是否发送数据及串口协议版本。 |
| ROSbridge 已连接但没有曲线 | 检查发布端 topic 名称、topic 类型、是否勾选并点击 **应用订阅**；查看健康状态是否为“数据静默”。 |
| 定位页没有轨迹 | 在 ROS 页连接；在任一页面勾选 FAST-LIO 里程计并应用；确认选定的里程计 topic 正在发布。 |
| ROSbridge 重启失败 | 检查 ROS 主机网络、SSH 免密登录、远端命令及页面错误信息。普通断线重连可直接使用 **连接**。 |
| 汇总无法开始 | 等待数据源检查结束；对离线或错误来源修复连接，或取消勾选；确认保存目录可写。 |
| 找不到记录 | 单模块记录和汇总记录保存位置不同；查看页面的“已保存”路径、所选保存对话框路径或汇总页 **打开目录**。 |
| rosbag 未出现在本地 | **开始车端 rosbag** 只在车端录制；停止后选中 session 并点 **同步到 Windows**，确认同步完成。 |

## 11. 技术参考与配置

调试串口帧及命令格式见 [Debug_UART_Protocol.md](Debug_UART_Protocol.md)。常用默认值定义在 [`src/app_config.py`](../src/app_config.py)，包括 ROSbridge 主机和端口、FAST-LIO topic、记录根目录、车端 rosbag 目录及压缩方式。可在启动程序前设置 `DEBUG_MONITOR_ROSBRIDGE_HOST`、`DEBUG_MONITOR_ROSBRIDGE_PORT`、`DEBUG_MONITOR_RECORDINGS_DIR` 等环境变量覆盖默认值；界面中可编辑的字段以当前界面输入为准。
